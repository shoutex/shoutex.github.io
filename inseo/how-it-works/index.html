How does the keyphrase scoring engine work?

InSEO starts from the keyphrase you enter, not from a generic checklist. You add up to four keywords and their synonyms, InSEO reads the page in your browser, checks each on-page element against those keywords and rolls the results into one diagnostic score.

You set the keyphrase

Up to four keywords, plus synonyms.

fractionalcmo
InSEO reads the page

Title, meta, headings, links, images and body copy, in the open tab.

Each check is scored

Every element gets its own percentage for your keyphrase.

One diagnostic

An overall on-page score plus what is missing and where.

Key point

The score is relative to your keyphrase. The same page can score high for one keyphrase and low for another, which is the point: it tells you whether this page is built for the search you want.

What does each check look at?

Here is what InSEO checks on every page and what we treat as a good result. These follow widely accepted on-page practice and Google's own documentation on influencing title links.

CheckWhat InSEO looks atWhat good looks like
Title

Whether the keyphrase appears in the title tag, how early, and whether the length suits search results.

Put the main keyword near the start and keep the title readable. Google may rewrite titles that don't describe the page.

Meta description

Whether a meta description exists, includes the keyphrase and fits a typical snippet.

Write one or two plain sentences that answer the search. A clear description earns the click.

Open Graph tags

Which og: tags are present for link previews.

At minimum: og:title, og:description, og:url, og:type and og:image.

URL

Whether the URL is readable and reflects the topic.

Short, lowercase, hyphenated, built around the topic. Avoid dates and IDs.

H1 tag

Whether there is one H1 and whether it carries the keyphrase.

One H1 that states the topic in the reader's words.

H2 to H5 tags

How many subheadings exist and how the page is structured.

Question-style subheadings that match what buyers ask work well for search and AI answers.

Images

Whether the page has images and whether they have alt text.

Use images that add meaning, with alt text that describes them in context.

Anchor links

The text of each link and where it points.

Descriptive anchors that tell readers and crawlers what the next page is about.

Body keywords

How often each keyword appears in the body copy.

Natural use across the page. Very low means the page may not be about the topic; very high reads as stuffing.

External links

Which outside domains the page cites, and how often.

A few authoritative sources that back up your claims.

What does a real InSEO report look like?

This is a real report, rebuilt in HTML. We ran InSEO on our fractional CMO cost answer with the keywords fractional and CMO. Open a row to see the detail InSEO shows.

What the report points to

Three fixes stand out: add one image with descriptive alt text, put the core phrase earlier in the title and H1, and link to a related blog post. None needs new content, only better use of what is already on the page. That is the kind of decision InSEO is built to speed up.

How should you act on the diagnostic?

Fix zeros first, then anything under 60%, then fine-tune the 70s and 80s. A page does not need 100% on every check; it needs every element pulling in the same direction as the search you want to win.

Hint

Run InSEO on the page that ranks first for your keyphrase, then on your own. The gaps between the two reports are usually your to-do list.
